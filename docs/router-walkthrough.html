The feedback router, one decision at a time

A good edit.
A second model.
One less blind guess.

Follow a small precision change as the router discovers it, shares it, and learns where it works.

We’ll use six example operators and three budgets. All numbers in the story are illustrative; the real implementation uses 54 operators.

09

Keep discovering new ideas.

The router reserves every fourth post-seed proposal for local exploration. If no transfer is available, it explores locally on the other turns too.

Local search cycles through budgets and alternates weight-changing and activation-only preferences. Tested policies are cached globally. Unique seeds and early-rejected candidates both count toward the allowance.

The idea to keep

Discover an edit locally.
Reuse it where the context fits.
Trust the measurement.

The router spends the next evaluation on a promising configuration. It adds no routing component to the final model.

Connect this story to the actual implementation
  • The real model has 54 independent operators and five choices: W4A8, W4A16, W8A8, W8A16 and FP32. A16 is integer activation quantization.
  • Defaults: eight evenly spaced storage budgets and 64 unique candidate evaluations. BitOps is reported without a default cap; an explicit --compute-fraction opts into a compute constraint.
  • Compatibility, resource feasibility and cache checks filter transfers. Remaining proposals are ranked by surrounding Hamming distance, then source error gain, source KL gain and stable tie ordering.
  • Fisher scores, activation ranges and model weights remain fixed. Only full measurements update best policies and successful-edit memory.
  • Early rejection stops only when accumulated mistakes already exceed every eligible incumbent’s total. Accuracy ties must finish for the KL comparison.
  • In the historical 24-candidate pilot (which used the former 75% compute cap), two transfers were tested. One improved search KL at tied accuracy; the other failed. The router and local-only run ended with identical held-out policies and predictions.

For exact candidate-by-candidate numbers, open the recorded pilot replay.
